# 🚀 Hugging Face Ecosystem Tutorials Repository

A complete tutorial series covering the **Hugging Face ecosystem** — from NLP to diffusion models, training optimization, deployment, and evaluation.

This repository is designed for **beginners to advanced learners** who want to build real-world AI applications using modern open-source tools.

---

# 📌 Purpose of This Repository

This repository helps you learn and implement:

- 🤖 Natural Language Processing (NLP)
- 🧠 Large Language Models (LLMs)
- 🎨 Image Generation (Diffusion Models)
- 🔊 Speech & Audio Processing
- ⚡ Model Training & Optimization
- 🚀 Model Deployment & Inference
- 📊 Evaluation & Metrics

---

# 📚 Core Libraries

## 🔤 Transformers
State-of-the-art library for NLP, vision, and audio models.

**Features:**
- Pretrained models (BERT, GPT, T5, LLaMA, Whisper)
- Text classification, summarization, translation
- Audio & vision model support

---

## 📦 Datasets
Efficient dataset loading and processing library.

**Features:**
- Hugging Face dataset hub access
- Streaming large datasets
- Multimodal datasets (text, image, audio)
- Custom dataset creation

---

## 🔠 Tokenizers
Fast and efficient tokenization library built in Rust.

**Features:**
- BPE, WordPiece, Unigram tokenization
- Extremely fast processing
- Custom tokenizer training

---

## 🤗 Hugging Face Hub
Central platform for models, datasets, and spaces.

**Features:**
- Upload & download models
- Version control for ML assets
- API-based integration

---

# 🔧 Training & Optimization

## ⚡ Accelerate
Simplifies multi-GPU/TPU training.

**Features:**
- Distributed training support
- Mixed precision (FP16/BF16)
- Easy PyTorch integration

---

## 🧩 PEFT (LoRA, QLoRA)
Parameter Efficient Fine-Tuning library.

**Features:**
- LoRA / QLoRA fine-tuning
- Memory-efficient training
- Works with large models on limited GPUs

---

## 🧪 TRL (Transformers Reinforcement Learning)
Used for RLHF training.

**Features:**
- PPO-based training
- Chatbot alignment
- Human feedback learning

---

## ⚙️ Optimum
Model optimization and acceleration toolkit.

**Features:**
- ONNX Runtime support
- TensorRT optimization
- Faster inference pipelines

---

# 🎨 Diffusion / Image Generation

## 🖼️ Diffusers
Library for image generation models.

**Features:**
- Stable Diffusion pipelines
- Text-to-image generation
- Image-to-image transformation
- Inpainting & outpainting

---

# 🔊 Audio / Speech

## 🎤 SpeechBrain
Speech processing toolkit.

**Features:**
- Speech recognition (ASR)
- Speaker recognition
- Speech enhancement

---

## 🎧 Transformers (Audio Support)
Supports audio models like Whisper.

**Features:**
- Speech-to-text (Whisper)
- Audio classification
- Text-to-speech models

---

## 🎼 Audio Datasets (Datasets Library)
- Load audio datasets easily

- Feature extraction support
